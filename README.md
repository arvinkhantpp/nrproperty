# NR Property

Website and admin panel for NR Property, a real-estate developer in Dhaka. Next.js 15 (App Router) with Payload CMS 3 in the same app, Postgres, Tailwind CSS v4 and next-intl (English at `/`, Bangla at `/bn`).

> Work in progress. A full client handover guide arrives in Phase 8.

## Run locally

Requirements: Node 20.9+, pnpm 10, Docker (or your own Postgres 16).

```bash
pnpm install
cp .env.example .env          # then set PAYLOAD_SECRET (openssl rand -hex 32)
docker compose up -d db       # Postgres on localhost:5432
pnpm dev
```

- Site: http://localhost:3000 · Bangla: http://localhost:3000/bn
- Admin: http://localhost:3000/admin (create the first admin user on first visit)
- Design system: http://localhost:3000/styleguide (development only)

## Scripts

| Command               | What it does                                                                                       |
| --------------------- | -------------------------------------------------------------------------------------------------- |
| `pnpm dev`            | Development server                                                                                 |
| `pnpm check`          | Lint + typecheck + production build                                                                |
| `pnpm screenshots`    | Full-page screenshots at 375/768/1440 into `docs/screenshots/_review` (dev server must be running) |
| `pnpm generate:types` | Regenerate `src/payload-types.ts` after changing collections                                       |

## Deploy

- **Vercel + Neon:** set the variables from `.env.example` in Vercel; `DATABASE_URL` is the Neon pooled connection string.
- **VPS:** `docker compose up -d --build` runs Postgres and the site.

## Project layout

```
src/app/(frontend)/[locale]   public site (en/bn)
src/app/(payload)             admin + API (generated by Payload)
src/collections, src/globals  CMS schema
src/components/ui             design-system components
src/styles/globals.css        design tokens (Tailwind v4 @theme)
src/messages                  UI strings (en.json, bn.json)
```
