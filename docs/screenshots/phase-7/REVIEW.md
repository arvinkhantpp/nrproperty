# Phase 7 design review

Pages: /blog, /blog/[slug], /construction-status, /apartments-in-[area] (with and without projects),
/nrb, /bn/blog, plus a project page for the new area breadcrumb. Widths 1440 / 768 / 375.

## Round 1
- Footer: the new Areas column pushed "Visit us" into a narrow fifth cell with a broken email.
  With four link columns, "Visit us" is now a full-width row under them.
- Blog post: "Keep reading" was empty when no other post shared the category. It now falls back
  to the latest posts.
- Construction status: two "starting soon / handed over" cards sat in a three-column grid with a gap.
  The grid now uses two columns when there are two cards.
- Area page: the enquiry form asked the visitor to pick a project from scratch. It now preselects
  the first project in that area.

## Round 2
- Construction status on phones: four site photos in a three-column strip left an orphan. Now a
  four-across strip.
- Checked in a production build: blog category filter, no console errors on any Phase 7 page.
